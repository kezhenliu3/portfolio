# 样本产出 — 脱敏声明

本目录公开的是 RAG 离线管线的"样本产出"。与报告类项目不同，本系统的产出是**评测指标与文档切块**，因此公开样本为：[评测数字表](eval-numbers_CN.md)（生产基线数字）与 [chunk 结构示例](chunk-examples_CN.md)（两条切块结构摘录）。英文版见 [README.md](README.md)、[eval-numbers.md](eval-numbers.md)、[chunk-examples.md](chunk-examples.md)。

## 脱敏声明

- **数字**：仅为系统指标（冻结测评集上的检索与裁判得分）。不公开任何题目文本、答案内容或内部文档。
- **Chunk 摘录**：两条来自语料中**已发表学术论文**的短片段，仅用于展示标题树锚点结构。不公开完整切块内容。
- **不含内部材料**：不公开源代码、配置文件、内部报告、公司名、内部工具名、API 密钥。
- **仅公开技术栈名称**：文中提及的所有工具（RAGAS、Milvus、MinerU、Langfuse、jieba/nltk、vLLM、DashScope）均为公开的开源或商业服务。

## 看什么

1. **#7 → #11 的迭代弧线** — 一个月、同一份冻结数据集、每一步都是单变量变更 + 预注册判定标准
2. **分难度基线** — 单跳与多跳查询各设不同门槛，门槛 = 实测均值 − 1σ，不是拍脑袋
3. **badcase 归因驱动变更** — 58 条零分样本先分型（检索失败 vs 指标口径问题），再动手修
4. **Chunk 结构** — `chapter`/`section` 字段展示了每个切块携带的标题树锚点

*这些文件产自系统自身的评测运行，无任何内容为演示而手工编写或编造。*
