# 样本 — 脱敏声明

本目录内所有文件在公开前均按仓库脱敏规则逐项审查。

- **媒体** — `media/` 中 7 张截图是公开产品微信小程序「九上阿」与一款第三方 App 对同一问题的回答对比。第三方 App 的品牌标识与界面中出现的用户姓名已做模糊/抹除处理；我方小程序品牌保留（公开产品）。`report-interpretation-demo.mp4` 为小程序自身的操作录屏——访客模式产品介绍 + 一份使用作者本人测试报告数据的解读演示（已授权）。视频已转码（H.264、faststart）、去除全部元数据，且音轨无语音内容（静音）。所有媒体文件中不含手机号、证件号或其他个人标识。
- **数字** — `metrics_CN.md` 分两层标注：开发测试实测值（延迟、测试通过数）与生产运营上报值（DAU、QPS、TTFT），后者明确标注为"方向性参考"，因仓库内不公开压测脚本。
- **问答** — `example-dialogues_CN.md` 为**脱敏改写**的示意性对话，并非真实用户对话，也非系统逐字输出；所有问题与数值均为虚构。
- **配置** — 配置驱动设计仅以文字与图示描述，不公开任何内部配置文件、片段或路径。
- **对比性质** — 同题对比为单次观察（anecdotal），不是基准评测；第三方 App 刻意不点名，其截图仅用于展示行为差异。

*截图与视频产自系统本身；问答示例为改写示意。不公开任何内部源码、配置或其他公司材料。*
